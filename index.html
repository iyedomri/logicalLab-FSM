🎛️ Générateur de Mots (Word Generator — TP3)

Comme dans NI Multisim : une fenêtre de mots (hex) que tu édites, un mot courant, et Step / Burst / Cycle. Les sorties 0, 1, 2… attaquent les variables d’entrée (Sortie 0 → B, Sortie 1 → A comme au TP).

📖 Ce que dit le TP (frequency, buffer, up counter, step/burst/cycle)
  • Frequency : fréquence de génération des mots (10 Hz au TP).
  • Buffer Size : nombre de mots de la séquence (0004 = 4 mots).
  • Initial / Final Window : premier et dernier mot de la séquence (0000 → 0003).
  • Up Counter : séquence croissante 0000, 0001, 0010, 0011 (≡ 0 → 1 → 2 → 3).
  • Step = un mot à la fois • Burst = la séquence une seule fois • Cycle = répétition continue.
  • Trigger : Internal = cadence par Frequency ; External = le mot avance à chaque front (bouton ⏱ Front → mot ou Step).
  • Branchement : Sortie 0 → B, Sortie 1 → A (le bit de poids faible sur la sortie 0).

📖 Ce que dit le TP (clocks/div, clock source, lecture des chronogrammes)
  • Clocks per division = 1 : l’échelle horizontale, 1 division par mot généré.
  • Internal Clock Rate = 10 Hz : fréquence d’acquisition, identique au générateur de mots pour échantillonner 1 mot par période.
  • Clock Source = Internal : l’analyseur se cadence lui-même (sinon il suit une horloge externe).
  • Branchement : voie 3 → S, voie 1 → A, voie 2 → B.
  • Lecture : niveau haut = 1, bas = 0 ; on compare les transitions de A et B avec S.
  • 2.6 Vérifier la table : le bloc ✓ Vérifier la table de vérité relit les chronogrammes et compare, mot par mot, les niveaux de A, B et S à la table théorique du circuit (badge ✔ conforme, ⚠ incomplet ou ✘ à revoir).

❓ Guide LogicLab FSM

1) Placer

Choisis un composant à gauche (bleu) → clique sur la grille blanche.

2) Renommer

Clique le nom sur le composant (ex: A) → tape a, b, c, F → la table utilisera ces noms + expressions comme b̅ et a+b̅.

3) Câbler

Clique point droite (sortie) → il clignote → clique point gauche (entrée). Fil apparaît.

4) Tester

Clique les interrupteurs (gris→bleu). LED verte=1. Temps réel.

5) Instruments TP3 — où ils sont

Comme dans Multisim (Simulate ▸ Instruments) : menu 🎛️ Simulate ▾ en haut → Word Generator, Logic Analyzer, Logic Converter (l’instrument choisi est mis en évidence dans l’onglet 📟).

6) Instruments TP3 (onglet 📟 Analyseur)

Générateur de mots : édite la fenêtre de mots (0000→0003), puis Step (1 mot), Burst (toute la séquence) ou Cycle (en boucle) — Sortie 0 → B, Sortie 1 → A comme au TP.
Analyseur logique : Clocks/div = 1, Internal Clock = 10 Hz, Clock Source = Internal → chronogrammes de A, B et S (1 division = 1 mot).
Convertisseur logique : les 6 boutons Conversions (circuit → table, table → équation, équation simplifiée, équation → table, équation → circuit, réalisation NAND).

7) Table intelligente

Active Mode intelligent à droite → la table affiche automatiquement entrées | intermédiaires (b̅, a·b, etc.) | sortie. Désactive pour n’avoir que entrées+sortie.

🧮 Équation → Circuit & Convertisseur NAND / NOR • Karnaugh / Quine-McCluskey • De Morgan • minimum de portes garanti

1️⃣ Saisis ton équation (ex: a.b + b' , (a+b)·c) → ⚡ Circuit direct, ou convertis en NAND / NOR optimisé au minimum de portes

Cible:
✓ Optimisé
Syntaxe: + = OU, . · * = ET, ' ̅ ! ¬ = NON, ⊕ xor, ⊙ xnor, ⊼ nand, ⊽ nor. Parentheses ok. Variables: a,b,c,d... 1 et 0 = constantes. 📥 Depuis la grille extrait l'équation du circuit déjà posé.

2️⃣ Choisis TES portes → conversion mixte optimisée (ex: NOR + NAND uniquement)

Le convertisseur compare toutes les formes possibles avec UNIQUEMENT les portes cochées (2 niveaux Karnaugh/QM, ¬F, De Morgan directe...) et garde celle avec le moins de portes. Même table de vérité garantie. NAND seul ou NOR seul = universel ✓

🎓 Règles appliquées (rappel FSM)

• a·1=a, a+0=a, a·0=0, a+1=1  • a·a̅=0, a+a̅=1 (complémentarité)
• a̅ = a ⊼ a (NOT via NAND) ou a̅ = a ⊽ a (via NOR)  • a·b = ¬(a⊼b) = (a⊼b)⊼(a⊼b)
• a+b = ¬(¬a·¬b) = (a⊼a) ⊼ (b⊼b) (De Morgan)  • ¬(a·b)= ¬a+¬b, ¬(a+b)= ¬a·¬b
• Distributivité: a·(b+c)=a·b+a·c  • Idempotence: a+a=a, a·a=a
